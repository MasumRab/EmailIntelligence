checked, what it found, and what the operator should do -- in that order.

### Requirements
1. The report is written to `reports/validation.md` and contains, per check: name, status, measured
   value, threshold and the command that reproduces it.
2. The verdict is one of `pass`, `pass with warnings`, `fail`, derived mechanically from the checks --
   never typed by the author of the run.
3. Failures appear first, and each carries the first ten lines of its evidence.
4. The report is generated by the same script that generates 011.8's stage report, in a
   validation-specific mode, not by a second formatter.

## Implementation Guide

Extend `scripts/validation_report.py` (008.8/011.8) with a `--mode validation` flag.

```bash
python scripts/validation_report.py --reports reports/ --mode validation --out reports/validation.md
head -30 reports/validation.md
```

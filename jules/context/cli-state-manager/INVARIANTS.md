# Invariants

- Never touch `.github/workflows/*` or create/modify `*.yml.DISABLED`.
- Never rebase a branch more than 15 files behind `main`.
- At most 3 files changed per step.
- No file losing more than 20 lines per step.
- Commit and push after each step.
- One PR per task.
- Never cite a documentation file as evidence that code is fixed; verify via runtime or testing.
